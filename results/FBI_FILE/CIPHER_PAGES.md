# Where the ciphers are in the FBI file

Page = PDF page. F1-F5 = Commons FBIZodiacFile1-5; P07-P11 = Vault parts 07-11. The file holds photocopies,
not originals. Best Z13 copy: about 32 px per circle (the circled glyph is 31-32 px wide), too small to
resolve the three circled symbols. Originals are held as evidence (pages stamped EVIDENCE: F3 p23, p179,
F4 p133, F5 p33).
